# Contributing

This repository contains my public GitHub profile README and supporting visual assets.

Small, relevant improvements are welcome, especially:

- documentation corrections
- accessibility improvements
- broken-link fixes
- improvements to the profile assets
- clearer project or engineering information

For changes that affect the profile presentation, please keep the existing dark green, teal, and off-white visual direction consistent.

## Pull requests

1. Explain what you changed and why.
2. Keep the scope small and focused.
3. Avoid unrelated changes.
4. Verify Markdown and asset references before submitting.

Thanks for helping keep the profile useful and maintainable.
